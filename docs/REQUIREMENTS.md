# R2Solver 需求规格说明书（REQUIREMENTS）

> 本文档用于**代码审查**：审查者应逐条对照需求编号与源代码，确认实现是否满足。
> 每条需求标注了对应源码位置（文件/函数）与验收方法。
> 状态：v1.3（2026-08-17）。标识：`[已实现]` / `[部分实现]` / `[未实现]`。

---

## 1. 引言

### 1.1 目的
实现一个搜索器，判定给定 \(a_1\) 下是否存在满足"等比部分和"性质的严格递增正整数序列（达到项目定义的 promising 深度），并对搜索过程提供可观测、可分析、可扩展的实现。

### 1.2 范围
- 搜索算法（初始段枚举、扩展、填充、promising 判定、剪枝）
- 日志与统计（多挂载日志、JSON 输出、进度）
- 模块化接口（搜索 / 剪枝 / 日志解耦）
- 配套分析工具（count_r2、路径验证）

### 1.3 术语
| 术语 | 含义 |
|---|---|
| \(T_n\) | 前 \(a_n\) 项之和：\(\sum_{i=1}^{a_n} a_i\) |
| 步长 / 块长 L | 相邻序列值之差 \(a_{n+1}-a_n\)，即新增块长度 |
| promising | 达到启发式深度阈值，判定"可无限延伸" |
| 剪枝 | 满足必要条件的预判，用于缩小搜索空间（不漏解） |

---

## 2. 数学问题定义

搜索严格递增正整数序列 \(a_1<a_2<\cdots\)，满足：

1. 相邻项差至少 2：\(a_{n+1}-a_n \ge 2\)
2. 部分和按序列值取前缀构成等比数列（公比 2）：
   \[
   T_{n+1}=2T_n,\qquad T_n=\sum_{i=1}^{a_n}a_i
   \]

**约束来源**：`r2solver.h`（State/阈值）、`search.c`（扩展逻辑）、附录 A（数学证明）。

## 3. 功能需求

### FR-1 初始段枚举
- **需求**：对给定 \(A=a_1\)，穷举初始段 \(a_2..a_{a_1}\)，满足 \(a_2 \in [A+2, 2A-2]\)、\(a_{i+1} \in [a_i+2,\ 2a_i-i]\)。
- **位置**：`search.c::enumerate_initial`、`r2solver_main.c`（a2 循环）。
- **验收**：a1=4 初始段恰为 15 个（`count_r2` 输出一致）；边界值与公式逐项核对。
- **状态**：`[已实现]`

### FR-2 单步扩展与块长确定
- **需求**：扩展时块长 \(L=a_{n+1}-a_n\) 由已填序列唯一确定（\(n+1\le m\) 恒成立）；仅当出现异常时走枚举分支。
- **位置**：`search.c::try_extend`（`old_n+1 <= old_m` 分支）。
- **验收**：代码审查确认固定 L 分支条件恒真；`L<2`、`L>m-n` 检查存在。
- **状态**：`[已实现]`

### FR-3 promising 判定
- **需求**：满足任一条件即宣告 promising 并保存完整序列快照：\(T_n>2^{60}\)、\(n>20\)、末项 \(a_{a_n}>10^8\)。
- **位置**：`search.c::try_extend` 开头；`state.c::save_promising_sequence`。
- **验收**：阈值宏 `LIMIT / PROMISING_N_THRESHOLD / PROMISING_ITEM_THRESHOLD` 可 `-D` 覆盖；命中后 `found_promising=true` 且停止搜索。
- **状态**：`[已实现]`

### FR-4 剪枝系统（必要条件，不漏解）
- **需求**：实现以下剪枝，且全部为严格必要条件：
  1. 全局下界 \(m\ge a_1+2(n-1)\)
  2. 全局上界 \(m\le \lfloor(\sqrt{(a_1-1)^2+4T_n}-(a_1-1))/2\rfloor\)
  3. 精细不等式（REFINED）
  4. 新增段最小和（MIN_SUM）：\(L(a_m+2)+L(L-1)\le T_n\)
  5. L 取上界额外限制（L_EXTRA）
  6. 填充内：项值上下界（\(v_{j+1}\ge v_j+2\)、\(v_{j+1}\le 2v_j-idx\)）、剩余最小和剪枝
  7. 相邻步长长度（v1.5）：\(L_{k+1}<2L_k\)（相邻段平均值必须严格递增），全量检查 k=1..m-2
  8. 相邻步长二次上界（v1.5）：\(L_{n+1}^2+L_{n+1}(T_n/L_n+1)\le 2T_n\)（比 2L_n 更紧，链式 3 层）
- **位置**：`prune.c`（1–5）、`search.cpp::fill_segment`（6）、`search.cpp::try_extend`（7–8）。
- **验收**：`prune_run_all` 依注册顺序执行；`count_r2`/`analyze_paths.ps1` 独立复核路径均满足全部约束（36/36 通过，0 非法）。
- **状态**：`[已实现]`

### FR-5 填充完整性（不漏解，v1.3 修复）
- **需求**：`fill_segment` 必须枚举新增块的所有合法填充；某个填充深层失败后须回溯继续枚举，不得提前返回。
- **位置**：`search.c::fill_segment`（`f->pos==L && need_sum==0` 分支）。
- **验收**：代码审查确认失败分支为 `top--; continue;`（而非 `return ok;`）；对照 `solverer_BUGREPORT.md` 证据链（随机探测器 n=22 路径 + 路径验证 36/36 合法）。
- **状态**：`[已实现]`（v1.3 修复）

### FR-6 日志系统（可自由挂载）
- **需求**：LogSink 接口（write/flush/close）；注册表支持多个 sink 同时挂载；搜索核心仅通过 `log_attempt` 与日志交互。
- **位置**：`r2log.h`、`log.c`、`log_*.c`。
- **验收**：`init_json_log` + `init_detailed_log` + `log_register(&stats_sink)` 三者同时启用可正常工作；`log_attempt` 广播给全部已注册 sink。
- **状态**：`[已实现]`

### FR-7 JSON 统计输出
- **需求**：输出 `r2_stats.json`，含每层节点数、层×失败原因、失败总计数、max_n、最深状态快照、耗时、promising 标记；每完成一个 a1 写盘。
- **位置**：`log_json.c`。
- **验收**：字段与口径符合 `README.md` 第 5 节；中途终止不丢已完成的 a1 数据。
- **状态**：`[已实现]`

### FR-8 进度输出
- **需求**：每 1 亿节点向 stderr 输出 `[进度] a1 / max_n / 节点数 / 耗时`。
- **位置**：`log_json.c::json_track_node`（经 `log_set_track_node` 挂接）。
- **验收**：长跑时可观察到周期性进度行。
- **状态**：`[已实现]`

### FR-9 模块化接口
- **需求**：搜索核心（search.c）、剪枝（prune.c）、日志（log_*.c）解耦；新增日志/剪枝无需修改搜索核心；依赖单向。
- **位置**：`r2solver.h`、`r2log.h`、`MODULE_SPEC.md`。
- **验收**：按 `MODULE_SPEC.md` 第 3/4 节步骤新增一个日志/剪枝模块，不触碰 search.c 即可生效。
- **状态**：`[已实现]`

### FR-10 确定性
- **需求**：搜索本身无随机性，相同输入（a1 范围、阈值）下结果与过程完全一致（JSON 节点数可复现）。
- **位置**：`search.c`、`log_json.c`。
- **验收**：同一配置运行两次，`r2_stats.json` 逐字节一致。
- **状态**：`[已实现]`（随机探测器 count_r2 属独立工具，不在本需求范围）

## 6. 约束与假设

1. **promising 为启发式判据**（FR-3），非"无限延展"的数学证明；其合理性属研究问题，不在本需求验收范围。
2. 剪枝必须是**严格必要条件**（FR-4）：误剪即引入漏解 bug（历史教训见 `solverer_BUGREPORT.md`）。
3. 搜索空间随 a1 超指数膨胀（a1=5 约 17 亿节点）：大 a1 的"可终止性"依赖剪枝强度，不视为缺陷，但要求可观测（NFR-3）。

## 附录 A：剪枝条件数学依据（必要条件）

1. **步长下界**：\(L\ge2\)（相邻差至少 2，问题定义）。
2. **步长上界**：\(L\le a_n-n\)（由 \(T_n<a_n\cdot a_{a_n}\) 与精细不等式导出）。
3. **a2 范围**：\(a_2\in[a_1+2, 2a_1-2]\)（n=1 时块和可行性）。
4. **精细不等式**：前缀和上界 ≥ 新增段最小和。
5. **全局上界**：\(a_n\le\lfloor(-(a_1-1)+\sqrt{(a_1-1)^2+4T_n})/2\rfloor\)（步长 ≥2 时前缀和 ≥ \(a_n(a_1+a_n-1)\)）。
6. **全局下界**：\(a_n\ge a_1+2(n-1)\)。
7. **剩余最小和**：剩余项最小取值 \(v+2, v+4,\dots\) 之和。
